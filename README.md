# redlisten-examples

Working example code for [Redlisten](https://redlisten.com), a public Reddit posts and comments API. Redlisten is not affiliated with Reddit, Inc.

Each folder is self-contained with its own README:

- [`slack-alerts`](./slack-alerts) -- get a Slack message when your brand is mentioned on Reddit
- [`discord-relay`](./discord-relay) -- post new subreddit threads into a Discord channel
- [`python-trends-chart`](./python-trends-chart) -- chart Reddit mention volume over time, single keyword or compared
- [`mcp-config`](./mcp-config) -- connect an AI agent to Reddit search via Redlisten's MCP server
